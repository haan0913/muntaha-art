# GPT Image 2 Design Prompt Pack

Use these for moodboards, hero textures, and non-final visual exploration. Do not imitate living artists or copy reference art.

## Site moodboard prompt

Create an editorial art portfolio website moodboard for a NYC-based artist named Muntaha. Visual direction: dark cinematic, personal fine-art studio diary, realism mixed with Bengali folk-art memory, surreal but not abstract. Palette: deep crimson red, indigo blue, oxidized green, warm turmeric yellow, blackened brown, antique paper. Avoid pastel colors. Elegant serif typography, subtle motion cues, gallery-grade restraint, immersive but still usable. Include homepage hero, gallery grid, artwork detail page, shop preview, and studio diary section. No copied artist styles. No real people.

## Hero background prompt

Create a dark cinematic website hero background texture for an artist portfolio. It should feel like oil paint, old paper, shadowed studio walls, and Bengali folk textile memory, but remain subtle enough for text readability. Palette: black, deep red, forest green, muted gold, dark blue. No abstract-expressionist splashes, no text, no logo, no recognizable people.

## Product card concept prompt

Design a high-end art shop product card system for prints and postcards. Mood: editorial, fine-art, dark cinematic, elegant serif typography, subtle gold linework, black/red/green/blue palette. It should feel premium but handmade. Show hover/detail states and price/variant display. No brand names except Muntaha.

## Studio diary section prompt

Create a website section concept for a studio diary: dark personal notebook, painter's archive, NYC night, realism, Bengali folk-memory motifs. Include three journal cards and one image panel. Subtle, readable, elegant, not pastel, not abstract.

## Live-site asset rule

Only use generated assets on the live site if Muntaha approves them and they do not imitate another artist's recognizable style. Label them internally as AI-assisted decorative assets, not artworks by Muntaha.
